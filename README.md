# VryBot - Interactive Discord Bot

VryBot is an interactive Discord bot designed to deliver short and funny responses. With a touch of sarcasm, it uses the **Google Gemini API** to generate dynamic and creative content.

---

## Features

- Responses driven by prompts that define the bot's personality
- Message history storage for more relevant context
- Safety settings to avoid inappropriate content

---

## Prerequisites

- Python 3.8 or higher
- A Discord bot API key
- A Google Gemini API key

---

## Installation

1. Clone the repository:
   ```bash
   git clone <REPOSITORY_URL>
   cd <DIRECTORY_NAME>
   ```

2. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate    # Linux/Mac
   venv\Scripts\activate       # Windows
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Create two text files in the project root:
   - `APIGEMINI.txt` — paste your Google Gemini API key
   - `APIDISCORDBOT.txt` — paste your Discord bot API key

---

## Usage

1. Run the bot:
   ```bash
   python <FILE_NAME>.py
   ```

2. In Discord, interact with the bot using commands that start with `v!`. For example:
   ```
   v! How are you doing?
   ```
